# Use the experimental JSON v2 package

Status: Decided.

On 2025-02-22 the commit `79abe0a` switched `chromedp` to
`github.com/go-json-experiment/json`, the experimental second version of the
JSON package.

On 2025-03-20 the commit `9335dc3` let a caller pass the marshal and
unmarshal options. The connection code in `conn.go` and `browser.go` uses the
`jsontext` package, and it allows invalid UTF-8.

Later the code moved to `encoding/json/v2` and `encoding/json/jsontext` of the
standard library, and `go.mod` no longer lists the experimental module. The
decision `2026-10-03-the-minimum-go-version-is-1-27.md` records the change.

The commit messages give no further reason. If a reason exists, add it here.
