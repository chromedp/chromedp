# Questions and ideas go to Discussions, and issues are for bugs

Status: Decided.

The maintainer decided on 2026-10-03 that `chromedp` moves its questions and
feature ideas to GitHub Discussions, as the `xo` projects did, and keeps the
issue tracker for bugs.

## What was done

GitHub Discussions was turned on for `chromedp/chromedp` on 2026-10-03, with the
default categories. The issue template was a single file, `.github/ISSUE_TEMPLATE`.
It is now `.github/ISSUE_TEMPLATE/bug.md`, with a bug report heading and a note
that questions belong in Discussions. A new file, `.github/ISSUE_TEMPLATE/config.yml`,
turns off blank issues and adds three links: Q&A, Ideas and Discord. The README
and `CONTRIBUTING.md` say where to ask.

## What was not done

Issues stay on. The tracker holds 180 open issues, and nothing was closed,
moved or locked. The `xo/usql` repository also keeps Issues on beside
Discussions.

## What remains

Turning Issues off, or moving old questions to Discussions, is not decided.
